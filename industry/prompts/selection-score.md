内部内容类型仅以下七种，与 taxonomy、content-understanding、structure 一致：
- macro_release：央行利率、降准、QE/QT、宏观数据或财政重大变化。
- policy_event：金融监管、交易、披露与制度规则。
- earnings：正式财报、盈利预警或业绩指引变化。
- corporate_event：经营、管理层、合同、处罚、诉讼或财务风险。
- capital_event：回购、分红、增发、融资、并购、资产出售、重组或控制权。
- market_event：资产供需、资金配置或有明确传导的市场风险事件。
- opinion_analysis：有出处的观点、解释、研究或预测，不能当事实。

分别对五个独立维度打 0–10 整数：
1. significance：改变企业盈利/现金流、融资成本、制度或行业格局的幅度。
2. surprise：相对原文明示预期或既有状态的信息增量；无预期数据不得编造超预期。
3. evidence：材料内支持核心事实的证据，区分实测/正式披露与未经核实的主张。
4. market_relevance：对覆盖市场、流动性、风险溢价或机构配置的传导广度与直接性。
5. durability：影响延续时间，区分长期结构变化与短暂行情/情绪。

按类型加权，不平均、不加奖励、不向门槛凑分。每行权重之和 = 10。
attentionScore = significance×w1 + surprise×w2 + evidence×w3 + market_relevance×w4 + durability×w5。

必须正常评价：央行加息、降息、降准、QE/QT；CPI/GDP/就业等重大数据；财政政策与证券监管重大变化；正式财报、盈利预警、重大指引变化；大规模回购、增发、分红变化；并购、资产出售、资本重组、控制权变化；重大合同；重大处罚、诉讼、财务问题；显著改变行业供需的事件；有明确金融传导的重大地缘事件。宏观新闻不因没有公司名而低分，正式财报不因篇幅短而低分，批准但尚未完成的交易按实际阶段评。

强制噪声上限（先约束维度，再照表合成，不能额外改分）：
- 纯指数或单股涨跌、无新增事实盘中快讯、普通投资者情绪：五个维度各 ≤ 2，纯价格变化本身不得高分。若含真正独立的盈利/政策/供需新事实，只评该事实，不给价格幅度加分。
- K线/技术指标预测、看涨看跌喊单、荐股、营销/课程/开户推广、标题党：五个维度各 ≤ 2。
- 无新增事实的券商评级、单纯目标价调整、重复转述、普通公司 PR、无实质变化例行公告：五个维度各 ≤ 3。来源官方也不豁免。
- 无证据传闻：evidence ≤ 1，significance、surprise、market_relevance、durability 各 ≤ 3。不把后果猜想当新增事实。
- 地缘事件无明确盈利、利率、融资、流动性、供需或制度传导：五个维度各 ≤ 2，不能凭事件震撼程度抬分。
- 观点只按可核查论据、推理增量和适用边界评价；不奖励方向性预测、名人身份、篇幅或口号。
